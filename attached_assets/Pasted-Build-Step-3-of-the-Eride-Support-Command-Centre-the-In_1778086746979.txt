Goal:
Create the first internal admin/support dashboard where Eride staff can view submitted support tickets.

Route:
- /admin/support/tickets

Purpose:
Allow internal Eride support/admin users to view, filter, and monitor all support tickets across:
- E-Migration Assist
- 8Beauty
- Eride General Support

Important:
Do not add authentication/permissions yet unless the existing app already has admin auth patterns.
Do not add Linear integration yet.
Do not add Sentry integration yet.
Do not add WhatsApp/email automation yet.
Do not build ticket detail editing yet.
Do not build full wallboard yet.
This step is only the internal ticket list/dashboard.

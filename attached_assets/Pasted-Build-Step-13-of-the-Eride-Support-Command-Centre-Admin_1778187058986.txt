- id
- organisationId
- templateKey
- templateName
- channel
- subject nullable
- bodyText
- bodyHtml nullable
- isActive
- createdAt
- updatedAt

Allowed templateKey values:
- ticket_received
- under_review
- more_info_needed
- escalated_to_engineering
- fixed
- resolved
- closed
- reopened
- custom

Allowed channel values:
- email
- whatsapp
- manual
- in_app

- templateKey + channel + organisationId should be unique
- templates belong to Eride Technologies organisation for MVP

Backend endpoints:

1. GET /api/support/settings

Return current Eride support settings.

2. PATCH /api/support/settings

Allow updating:
- supportDisplayName
- supportEmailFrom
- supportEmailReplyTo
- defaultSenderName
- defaultSenderRole
- publicTicketTokenTtlMinutes
- allowPublicReplies
- allowPublicAttachments

Validation:
- email fields must be valid or safe formatted email strings
- token TTL must be between 5 and 1440 minutes
- organisation must be Eride Technologies

3. GET /api/support/templates

Filters:
- channel optional
- templateKey optional
- isActive optional

Return templates for Eride organisation.

4. GET /api/support/templates/:id

Return one template.

5. PATCH /api/support/templates/:id

Allow updating:
- templateName
- subject
- bodyText
- bodyHtml
- isActive

Validation:
- bodyText required
- subject required for email templates except custom if existing convention allows
- template must belong to Eride Technologies organisation
- do not allow unsafe script tags in bodyHtml
- if bodyHtml is provided, sanitize or reject unsafe HTML

6. POST /api/support/templates/preview

Input:
- templateKey
- channel
- ticketId optional
- bodyText optional
- subject optional

Return:
- renderedSubject
- renderedBodyText
- renderedBodyHtml if available

Use an existing ticket if ticketId is provided, otherwise use sample ticket data.

Backend integration changes:

1. Update email template generation:
When sending template email, first try to load active support_message_templates for:
organisationId = Eride
templateKey = messageType
channel = email

If found:
- render with ticket variables
- use admin-managed template

If not found:
- fallback to existing hardcoded safe template

2. Update communication draft/template copy buttons:
For manual templates, first use support_message_templates channel = manual where available.
Fallback to existing hardcoded templates.
